# RFID-Based Warehouse Management System

##  Overview
This project is a full-stack Warehouse Management System designed to improve inventory tracking and management using RFID technology. It enables real-time monitoring of products, stock updates, and efficient warehouse operations. The system is connected to a Microsoft SQL Server database and deployed on AWS cloud services.

---

##  Features
- Add, update, and delete products
- Track inventory in real-time
- RFID-based product identification and simulation
- Search products by name or RFID tag
- Monitor stock levels and availability
- Generate basic inventory reports

---

##  Technologies Used
- Frontend: HTML, CSS, JavaScript / or UI framework (if used)
- Backend: C# / Java (based on implementation)
- Database: Microsoft SQL Server
- Cloud Deployment: AWS
- RFID Concept Integration

---

##  System Architecture
- User Interface (Frontend)
- Application Layer (Backend Logic)
- Database Layer (SQL Server)
- Cloud Hosting (AWS)

---

##  Project Objective
The goal of this project is to automate warehouse operations using RFID technology to enhance accuracy, reduce manual errors, and improve inventory management efficiency.
